HEADING                                                      *gutenberg.heading*

Read and edit ATX markdown headings (`# foo`, `## bar`, ...). Setext-style
underline headings are not supported. All functions accept an optional
`gutenberg.Context.Partial` (see |gutenberg.context|) and default to the
current buffer and cursor.

A heading is represented by a plain table:
>lua
  ---@class gutenberg.heading.Heading
  ---@field level integer  -- 1..6
  ---@field text string

is_heading({ctx})                                  *gutenberg.heading.is_heading*
    Returns `true` when the cursor is on an ATX heading. Use this to gate
    `read`, which errors otherwise.

read({ctx})                                            *gutenberg.heading.read*
    Returns the heading containing the cursor along with its `TSNode`
    (type `atx_heading`). Errors when the cursor is not on a heading.

create({fields})                                     *gutenberg.heading.create*
    Builds a heading from `{ level?, text? }`. Missing fields fall back to
    `gutenberg.heading.Config` (default `level = 1`, `text = ''`).
    Errors when `level` is outside 1..6.

render({heading})                                    *gutenberg.heading.render*
    Renders a heading to a single line of buffer text (`# text`).

replace({node}, {headings}, {ctx})                  *gutenberg.heading.replace*
    Replaces the range of `node` with the rendered headings in a single
    buffer update. Pass an empty list to delete the heading.

get_level({h})                                    *gutenberg.heading.get_level*
set_level({h}, {level})                           *gutenberg.heading.set_level*
    Read or write the heading level. `set_level` errors when `level` is
    not an integer in 1..6.

get_text({h})                                      *gutenberg.heading.get_text*
set_text({h}, {text})                              *gutenberg.heading.set_text*
    Read or write the heading text (everything after the `#` markers).

list({ctx})                                            *gutenberg.heading.list*
    Returns every ATX heading in the buffer in document order as
    `{ heading, node }` entries. Useful for tables of contents and
    pickers.

find_next({ctx}, {opts})                          *gutenberg.heading.find_next*
find_prev({ctx}, {opts})                          *gutenberg.heading.find_prev*
    Returns the nearest heading strictly after / before the cursor row,
    or `nil` when none qualifies. `opts` is an optional table with
    `min_level` and `max_level` filters. Neither helper moves the
    cursor; the caller decides how to act on the result.

find_parent({ctx})                              *gutenberg.heading.find_parent*
    Returns the heading governing the cursor's section: the closest
    preceding heading at a level that contains the cursor's region. When
    the cursor is itself on a heading, returns the closest preceding
    heading with strictly smaller level (its parent), or `nil`.

TABLES                                                         *gutenberg.table*

GFM pipe table primitives. Read a table at the cursor, edit the in-memory
struct, and write it back as a single buffer update.

                                                       *gutenberg.table.Table*
A parsed table is a plain struct: >lua

  ---@class gutenberg.table.Table
  ---@field alignments gutenberg.table.Alignment[]
  ---@field headers string[]
  ---@field rows string[][]
<
                                                   *gutenberg.table.Alignment*
Per-column alignment is one of: `'none'`, `'left'`, `'center'`, `'right'`.

                                                      *gutenberg.table.is_table()*
`require('gutenberg.table').is_table({ctx})`

Returns true if {ctx}'s cursor is on a pipe table. Gate calls to `read` with
this. {ctx} is a `gutenberg.Context.Partial`; missing fields default to the
current buffer and window cursor.

                                                         *gutenberg.table.read()*
`require('gutenberg.table').read({ctx})`

Reads the pipe table containing the cursor. Errors if the cursor isn't on a
pipe table. Returns the parsed |gutenberg.table.Table| and the underlying
`pipe_table` `TSNode`. Pass the node to `replace` to write changes back.

Cell text is trimmed.

                                                       *gutenberg.table.create()*
`require('gutenberg.table').create({fields})`

Constructs a |gutenberg.table.Table| from explicit fields. With no fields,
returns a 1-column table with an empty header. When `headers` is given but
`alignments` is not, alignments default to the configured
`default_alignment` (see |gutenberg.config|) per header column.

                                                       *gutenberg.table.render()*
`require('gutenberg.table').render({table})`

Renders {table} to a list of lines (header, delimiter, body…). Each column
is padded to the max width across the header, body, and a 3-character
minimum delimiter.

                                                      *gutenberg.table.replace()*
`require('gutenberg.table').replace({node}, {tables}, {ctx})`

Replaces {node}'s range with the rendered {tables} in a single buffer
update. Pass an empty list to delete. Multiple tables are separated by a
blank line so the markdown parser keeps them distinct.

                                                     *gutenberg.table.get_cell()*
                                                     *gutenberg.table.set_cell()*
`require('gutenberg.table').get_cell({table}, {row}, {col})`
`require('gutenberg.table').set_cell({table}, {row}, {col}, {text})`

Read or write a cell. Row 0 is the header; rows 1..N are body rows. Columns
are 1-indexed. Errors on out-of-range indices.

                                                *gutenberg.table.get_alignment()*
                                                *gutenberg.table.set_alignment()*
`require('gutenberg.table').get_alignment({table}, {col})`
`require('gutenberg.table').set_alignment({table}, {col}, {alignment})`

Read or write a column's |gutenberg.table.Alignment|. Errors on
out-of-range indices.

CONFIG                                                        *gutenberg.config*

`gutenberg.setup` accepts a `gutenberg.Config` table:
>lua
  ---@class gutenberg.list.Config
  ---@field marker string  -- default bullet marker for new items

  ---@class gutenberg.heading.Config
  ---@field level integer  -- default level for new headings (1..6)

  ---@class gutenberg.table.Config
  ---@field default_alignment gutenberg.table.Alignment

  ---@class gutenberg.Config
  ---@field list gutenberg.list.Config
  ---@field heading gutenberg.heading.Config
  ---@field table gutenberg.table.Config
