LIST                                                            *gutenberg.list*

Read and edit markdown list items. A list item is one row of bullet (`-`,
`*`, `+`) or ordered (`1.`) marker plus optional checkbox and text. Nested
items are themselves `list_item` nodes inside a child `list`.

A `gutenberg.list.Item` table has these fields: >lua
    {
      indent = '',     -- leading whitespace before the marker
      marker = '-',    -- '-', '*', '+', or e.g. '1.'
      checkbox = nil,  -- nil, ' ', 'x', or any single-char state
      text = 'foo',    -- content after marker (and checkbox, if present)
    }
<
                                                  *gutenberg.list.is_list_item*
is_list_item({ctx})
    Whether the cursor is on a list item. Gate calls to `read` with this.

                                                          *gutenberg.list.read*
read({ctx})
    Read the item containing the cursor. Returns
    `(gutenberg.list.Item, TSNode)`. Errors when the cursor isn't on a
    list item.

                                                        *gutenberg.list.create*
create({fields})
    Build an item from `{ indent?, marker?, checkbox?, text? }`. Missing
    fields fall back to `gutenberg.list.Config` (default `marker = '-'`).

                                                        *gutenberg.list.render*
render({item})
    Render an item to a single line of buffer text.

                                                       *gutenberg.list.replace*
replace({node}, {items}, {ctx})
    Replace `node`'s marker row with the rendered `items` in a single
    buffer update. Pass an empty list to delete the item. To insert a
    sibling, pass `{ existing, new }` (append) or `{ new, existing }`
    (prepend) — no helper needed.

                                                     *gutenberg.list.read_list*
read_list({ctx})
    Read every direct sibling of the cursor's item. Returns
    `({ item, node }[], list_node)` in document order. The `list_node` is
    the parent `list` TSNode — pass it back to `replace_list`. Errors when
    the cursor isn't on a list item.

                                                  *gutenberg.list.replace_list*
replace_list({list_node}, {entries}, {ctx})
    Rewrite the marker rows of each entry in a single buffer update.
    Nested children are preserved verbatim. Use to switch markers across
    siblings (e.g. unordered → ordered): `read_list`, mutate each
    entry's `item` with `set_marker`, then `replace_list`.

Field accessors:                                          *gutenberg.list-accessors*
    `get_marker(item)` / `set_marker(item, marker)`
    `get_checkbox(item)` / `set_checkbox(item, state)`
        Raw checkbox character. Pass nil to remove.
    `is_checked(item)` / `set_checked(item, checked)`
        Boolean view; `set_checked` adds a checkbox if absent.

HEADING                                                      *gutenberg.heading*

Read and edit ATX markdown headings (`# foo`, `## bar`, ...). Setext-style
underline headings are not supported. All functions accept an optional
`gutenberg.Context.Partial` (see |gutenberg.context|) and default to the
current buffer and cursor.

A heading is represented by a plain table:
>lua
  ---@class gutenberg.heading.Heading
  ---@field level integer  -- 1..6
  ---@field text string

is_heading({ctx})                                  *gutenberg.heading.is_heading*
    Returns `true` when the cursor is on an ATX heading. Use this to gate
    `read`, which errors otherwise.

read({ctx})                                            *gutenberg.heading.read*
    Returns the heading containing the cursor along with its `TSNode`
    (type `atx_heading`). Errors when the cursor is not on a heading.

create({fields})                                     *gutenberg.heading.create*
    Builds a heading from `{ level?, text? }`. Missing fields fall back to
    `gutenberg.heading.Config` (default `level = 1`, `text = ''`).
    Errors when `level` is outside 1..6.

render({heading})                                    *gutenberg.heading.render*
    Renders a heading to a single line of buffer text (`# text`).

replace({node}, {headings}, {ctx})                  *gutenberg.heading.replace*
    Replaces the range of `node` with the rendered headings in a single
    buffer update. Pass an empty list to delete the heading.

get_level({h})                                    *gutenberg.heading.get_level*
set_level({h}, {level})                           *gutenberg.heading.set_level*
    Read or write the heading level. `set_level` errors when `level` is
    not an integer in 1..6.

get_text({h})                                      *gutenberg.heading.get_text*
set_text({h}, {text})                              *gutenberg.heading.set_text*
    Read or write the heading text (everything after the `#` markers).

list({ctx})                                            *gutenberg.heading.list*
    Returns every ATX heading in the buffer in document order as
    `{ heading, node }` entries. Useful for tables of contents and
    pickers.

find_next({ctx}, {opts})                          *gutenberg.heading.find_next*
find_prev({ctx}, {opts})                          *gutenberg.heading.find_prev*
    Returns the nearest heading strictly after / before the cursor row,
    or `nil` when none qualifies. `opts` is an optional table with
    `min_level` and `max_level` filters. Neither helper moves the
    cursor; the caller decides how to act on the result.

find_parent({ctx})                              *gutenberg.heading.find_parent*
    Returns the heading governing the cursor's section: the closest
    preceding heading at a level that contains the cursor's region. When
    the cursor is itself on a heading, returns the closest preceding
    heading with strictly smaller level (its parent), or `nil`.

TABLES                                                         *gutenberg.table*

GFM pipe table primitives. Read a table at the cursor, edit the in-memory
struct, and write it back as a single buffer update.

                                                       *gutenberg.table.Table*
A parsed table is a plain struct: >lua

  ---@class gutenberg.table.Table
  ---@field alignments gutenberg.table.Alignment[]
  ---@field headers string[]
  ---@field rows string[][]
<
                                                   *gutenberg.table.Alignment*
Per-column alignment is one of: `'none'`, `'left'`, `'center'`, `'right'`.

                                                      *gutenberg.table.is_table()*
`require('gutenberg.table').is_table({ctx})`

Returns true if {ctx}'s cursor is on a pipe table. Gate calls to `read` with
this. {ctx} is a `gutenberg.Context.Partial`; missing fields default to the
current buffer and window cursor.

                                                         *gutenberg.table.read()*
`require('gutenberg.table').read({ctx})`

Reads the pipe table containing the cursor. Errors if the cursor isn't on a
pipe table. Returns the parsed |gutenberg.table.Table| and the underlying
`pipe_table` `TSNode`. Pass the node to `replace` to write changes back.

Cell text is trimmed.

                                                       *gutenberg.table.create()*
`require('gutenberg.table').create({fields})`

Constructs a |gutenberg.table.Table| from explicit fields. With no fields,
returns a 1-column table with an empty header. When `headers` is given but
`alignments` is not, alignments default to the configured
`default_alignment` (see |gutenberg.config|) per header column.

                                                       *gutenberg.table.render()*
`require('gutenberg.table').render({table})`

Renders {table} to a list of lines (header, delimiter, body…). Each column
is padded to the max width across the header, body, and a 3-character
minimum delimiter.

                                                      *gutenberg.table.replace()*
`require('gutenberg.table').replace({node}, {tables}, {ctx})`

Replaces {node}'s range with the rendered {tables} in a single buffer
update. Pass an empty list to delete. Multiple tables are separated by a
blank line so the markdown parser keeps them distinct.

                                                     *gutenberg.table.get_cell()*
                                                     *gutenberg.table.set_cell()*
`require('gutenberg.table').get_cell({table}, {row}, {col})`
`require('gutenberg.table').set_cell({table}, {row}, {col}, {text})`

Read or write a cell. Row 0 is the header; rows 1..N are body rows. Columns
are 1-indexed. Errors on out-of-range indices.

                                                *gutenberg.table.get_alignment()*
                                                *gutenberg.table.set_alignment()*
`require('gutenberg.table').get_alignment({table}, {col})`
`require('gutenberg.table').set_alignment({table}, {col}, {alignment})`

Read or write a column's |gutenberg.table.Alignment|. Errors on
out-of-range indices.

CODE BLOCK                                                *gutenberg.code_block*

Read, build, and rewrite fenced markdown code blocks. Indented (4-space) code
blocks are out of scope — fenced only.

A `gutenberg.code_block.CodeBlock` table has these fields: >lua
    {
      indent = '',          -- leading whitespace before the opening fence
      fence = '`',          -- '`' or '~'
      fence_length = 3,     -- count of fence chars on the opening fence (>= 3)
      info_string = 'lua',  -- everything after the opening fence (verbatim)
      content = { 'foo' },  -- one entry per content line, no trailing newline
    }
<
The `info_string` is stored as-is so callers can carry attributes (for example
`{lua title="x"}`) through a round trip. Use |gutenberg.code_block.get_language|
and |gutenberg.code_block.set_language| to manipulate just the leading token.

                                       *gutenberg.code_block.is_code_block()*
code_block.is_code_block({ctx})
    Returns true when the cursor is inside a fenced code block (opening
    fence, content, or closing fence). Gate calls to `read` with this.

    Parameters: ~
      • {ctx} (`gutenberg.Context.Partial?`)

    Return: ~
      `boolean`

                                              *gutenberg.code_block.read()*
code_block.read({ctx})
    Read the fenced code block containing the cursor. Errors when the cursor
    isn't on a code block. The returned `TSNode` captures the block's range
    for |gutenberg.code_block.replace|.

    Parameters: ~
      • {ctx} (`gutenberg.Context.Partial?`)

    Return: ~
      `gutenberg.code_block.CodeBlock, TSNode`

                                            *gutenberg.code_block.create()*
code_block.create({fields})
    Construct a code block from explicit fields. Missing fields fall back
    to the configured defaults (see |gutenberg.setup|).

    Parameters: ~
      • {fields} (`{ indent?, fence?, fence_length?, info_string?, content? }`)

    Return: ~
      `gutenberg.code_block.CodeBlock`

                                            *gutenberg.code_block.render()*
code_block.render({block})
    Render a block to buffer lines: opening fence, content, closing fence.
    Content lines are emitted verbatim — they carry their own indentation
    and are NOT auto-escalated when they look like a closing fence. Bump
    `fence_length` yourself when content contains a longer-or-equal run of
    the fence character.

    Parameters: ~
      • {block} (`gutenberg.code_block.CodeBlock`)

    Return: ~
      `string[]`

                                           *gutenberg.code_block.replace()*
code_block.replace({node}, {blocks}, {ctx})
    Replace `node`'s range with the rendered blocks in a single buffer
    update. Pass an empty `blocks` list to delete the node.

    Parameters: ~
      • {node}   (`TSNode`)
      • {blocks} (`gutenberg.code_block.CodeBlock[]`)
      • {ctx}    (`gutenberg.Context.Partial?`)

                                  *gutenberg.code_block.get_info_string()*
                                  *gutenberg.code_block.set_info_string()*
code_block.get_info_string({block})
code_block.set_info_string({block}, {info_string})
    Read or replace the entire info string verbatim.

                                       *gutenberg.code_block.get_content()*
                                       *gutenberg.code_block.set_content()*
code_block.get_content({block})
code_block.set_content({block}, {lines})
    Read or replace the block's content lines.

                                      *gutenberg.code_block.get_language()*
code_block.get_language({block})
    The first whitespace-delimited token of the info string. Returns `''`
    when the info string is empty.

                                      *gutenberg.code_block.set_language()*
code_block.set_language({block}, {language})
    Replace the leading-language portion of the info string, preserving any
    trailing attributes after the first whitespace. For example, calling
    `set_language(block, 'python')` on an info string `'lua title="x"'`
    yields `'python title="x"'`.

LINK                                                          *gutenberg.link*

Parse and edit markdown links. Distinguishes inline links, reference links
(full, collapsed, shortcut), and URI autolinks. Images are not links and are
skipped.

`gutenberg.link.Kind` is one of:
    `'inline'`              `[text](url)` (with optional title)
    `'reference_full'`      `[text][label]`
    `'reference_collapsed'` `[text][]`
    `'reference_shortcut'`  `[text]`
    `'autolink'`            `<url>`

Special characters in `text`, `url`, `title`, and `label` are NOT escaped by
`render`. Pre-escape any user input as needed.

                                                          *gutenberg.link.is_link()*
gutenberg.link.is_link({ctx})
    Whether the cursor (or `ctx`) is inside a link node. Returns false on
    images and link reference definitions.

                                                             *gutenberg.link.read()*
gutenberg.link.read({ctx})
    Read the link at the cursor. Returns `(gutenberg.link.Link, TSNode)`.
    The node spans the link's exact range — pass it to `replace`. Errors if
    the cursor is not on a link; gate with `is_link`.

                                                           *gutenberg.link.create()*
gutenberg.link.create({fields})
    Construct a `gutenberg.link.Link` from explicit fields. `kind` defaults
    to `gutenberg.link.Config.default_kind` (`'inline'`). Validates that the
    fields required for the kind are present; errors otherwise.

                                                           *gutenberg.link.render()*
gutenberg.link.render({link})
    Render a link to its literal markdown source. Reverse of `read`.

                                                          *gutenberg.link.replace()*
gutenberg.link.replace({node}, {links}, {ctx})
    Replace `node`'s exact range with the rendered concatenation of `links`.
    Pass an empty list to delete the link. Multiple links concatenate with
    no separator — the caller adds spacing if needed. Single buffer write.

                                                    *gutenberg.link.is_definition()*
gutenberg.link.is_definition({ctx})
    Whether the cursor is inside a `link_reference_definition`.

                                                  *gutenberg.link.read_definition()*
gutenberg.link.read_definition({ctx})
    Read the definition at the cursor. Returns
    `(gutenberg.link.Definition, TSNode)`. Errors if not on a definition.

                                                      *gutenberg.link.definitions()*
gutenberg.link.definitions({ctx})
    Return every link reference definition in the buffer, keyed by the
    lowercased label.

                                                          *gutenberg.link.resolve()*
gutenberg.link.resolve({link}, {defs})
    Look up a `reference_*` link's definition in `defs`. Returns nil for
    inline and autolink kinds, or when the label is not defined.

Field accessors:                                          *gutenberg.link-accessors*
    `get_url(link)` / `set_url(link, url)`
        Inline and autolink only; setters error on `reference_*` (use a
        definition instead).
    `get_text(link)` / `set_text(link, text)`
        Errors on autolinks. Setting text on collapsed/shortcut also
        updates the label so renders stay correct.
    `get_title(link)` / `set_title(link, title)`
        Inline links only. Pass nil to remove.
    `get_label(link)` / `set_label(link, label)`
        Reference_full only; collapsed/shortcut derive their label from
        text, so set via `set_text` instead.
    `get_kind(link)` / `set_kind(link, kind)`
        Mutate the kind in place. The caller is responsible for ensuring
        the link's other fields match the new kind's requirements.

CONFIG                                                        *gutenberg.config*

`gutenberg.setup` accepts a `gutenberg.Config` table:
>lua
  ---@class gutenberg.list.Config
  ---@field marker string  -- default bullet marker for new items

  ---@class gutenberg.heading.Config
  ---@field level integer  -- default level for new headings (1..6)

  ---@class gutenberg.table.Config
  ---@field default_alignment gutenberg.table.Alignment

  ---@class gutenberg.code_block.Config
  ---@field fence gutenberg.code_block.Fence  -- default fence char
  ---@field fence_length integer              -- default fence length (>= 3)

  ---@class gutenberg.link.Config
  ---@field default_kind gutenberg.link.Kind

  ---@class gutenberg.Config
  ---@field list gutenberg.list.Config
  ---@field heading gutenberg.heading.Config
  ---@field table gutenberg.table.Config
  ---@field code_block gutenberg.code_block.Config
  ---@field link gutenberg.link.Config
